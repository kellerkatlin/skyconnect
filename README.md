# SkyConnect

Trabajo 04 — Matemática Discreta · 1AMA0708 · UPC Grupo 1 · 2026

Análisis de la red de rutas de Avianca/TACA mediante matrices de conectividad
y un planificador de viaje multi-criterio (costo, tiempo, balance).

## Desarrollo

```
npm install
npm run dev
```

## Build de producción

```
npm run build
```

Genera `dist/` con la app estática, lista para abrir el `index.html`
directamente en cualquier navegador o desplegar en cualquier hosting estático.
